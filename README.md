# SkillSwap India — Formatted

Modernized presentation layer for the SkillSwap India Flask + HTML application.

## Run

```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Deploy

Build:
`pip install -r requirements.txt`

Start:
`gunicorn app:app`

The visual formatting is contained in the HTML and does not require Supabase.
