# 🔄 SkillSwap India

### Learn. Teach. Connect.

SkillSwap India is a peer-to-peer skill exchange platform that helps people **share what they know, learn new skills, and connect with others**.

Instead of simply consuming courses or paying for every learning opportunity, SkillSwap encourages people to exchange knowledge with each other.

> **Everyone has something to teach. Everyone has something to learn.**

---

## ✨ Features

### 🔍 Discover Skills

* Search for people based on the skills they offer.
* Explore different skill categories.
* Find potential learning partners through skill matching.

### 🤝 Skill Matching

* Discover users whose skills complement your learning goals.
* View suggested matches and compatibility information.
* Send connection requests to potential skill partners.

### 👤 User Profiles

* Create and manage your personal profile.
* Showcase skills you can teach.
* Add skills you want to learn.
* View ratings and other profile information.

### 📩 Connection Requests

* Send skill-exchange requests.
* View incoming and outgoing requests.
* Accept or manage connection requests.

### ⭐ Ratings & Reviews

* Build trust within the community.
* Review your learning and teaching experiences.
* Use ratings to help identify reliable skill partners.

### 📊 Dashboard

* Manage your connections and requests.
* Keep track of your SkillSwap activity.
* View relevant profile and interaction information.

### 🇮🇳 Built for India

SkillSwap India is designed with an Indian community-focused experience, making it easier for people to discover and exchange skills with others.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Abhiram1318/Skill-Swap.git
```

### 2. Open the project

```bash
cd Skill-Swap
```

### 3. Run the application

Since the project is a web application, you can open `index.html` in a browser.

For the best development experience, use a local development server such as VS Code's **Live Server** extension.

## 🔥 Firebase Configuration

The project includes Firebase configuration and database security rules.

Before deploying your own version, make sure your Firebase project is configured correctly and that your Firebase credentials are appropriate for the environment.

Do **not** commit private credentials, service-account keys, or other sensitive secrets to GitHub.
